Catatan untuk Developer:

Jika mengalami error "Failed to fetch" saat testing di localhost atau Visual Studio Code, ini mungkin disebabkan oleh masalah CORS. Solusi:

  1. Buka script.js dan set TEST_MODE = true untuk testing offline
  2. Atau uncomment baris penggunaan CORS proxy
  3. Upload ke web hosting sebenarnya untuk penggunaan produksi
  4. Gunakan ekstensi browser untuk menonaktifkan CORS saat development
